# 🌍 PLANORA – AI Travel Planner

**PLANORA** is a smart, responsive web application designed to simplify the travel planning process. It combines algorithmic itinerary generation with real-time data to provide users with personalized travel plans, weather updates, and unique astrological travel insights.

## ✨ Features

### 1. 🤖 AI Itinerary Generator
- **Custom Logic:** Generates day-by-day travel plans based on **Destination**, **Budget**, and **Duration**.
- **Budget Adaptation:** Automatically adjusts recommendations (transport, food, hotels) based on three tier levels: Backpacker, Comfort, and Luxury.
- **Rich Data:** Provides specific historical facts, food recommendations, and cafe spots for popular Indian destinations (Goa, Manali, Jaipur, etc.) with a fallback generator for other cities.

### 2. 🌤️ Real-Time Weather Integration
- Fetches live weather data using the **Open-Meteo API**.
- Displays temperature, humidity, wind speed, and weather conditions for the selected destination before booking.
- **Geocoding:** Converts city names to latitude/longitude automatically to fetch accurate data.

### 3. 🔮 Travel Astrology
- A fun, unique feature that calculates the user's Zodiac sign based on their Date of Birth.
- Provides personalized travel predictions and "Lucky Travel Dates" based on astrological logic.

### 4. 💻 Modern UI/UX
- **Responsive Design:** Fully responsive layout built with **Bootstrap 5**.
- **Glassmorphism:** Uses modern CSS glass effects for popups and cards.
- **Interactive Elements:** Smooth scrolling, animated modals, and a simulated AI chatbot interface.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Bootstrap 5.3.2, Custom CSS (Animations, Gradients)
- **APIs:** [Open-Meteo Weather API](https://open-meteo.com/), Open-Meteo Geocoding API
- **Version Control:** Git & GitHub
